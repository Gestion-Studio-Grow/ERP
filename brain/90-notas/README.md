# 📝 Zona humana — captura libre

Esta carpeta **no la toca `npm run brain`**. Escribí lo que quieras: ideas sueltas, pendientes,
apuntes de una llamada con un cliente, lo que se te ocurra en el celular.

**Regla de higiene:** cuando una nota de acá se vuelve una decisión, un guardarraíl o un método,
**se muda a `docs/`** (ADR, `lecciones-aprendidas/registro.md`, o `metodologia/`) y acá queda a lo
sumo un link. El vault indexa; no acumula conocimiento que debería estar en el territorio.

Convención sugerida para capturar rápido: `YYYY-MM-DD-tema.md`.
