`claude/ch-nivel-bp`, 18/10/2026) y **qué debería hacer**. El formato es el de Break Point
(`docs/tenants/breakpoint/REINGENIERIA.md` §4). La columna «Test» dice qué lo prueba: un test unitario (`*.test.ts`) o
el recorrido E2E (`npm run test:ch-uat`, id del paso).

mejorarlo · 🔴 hueco, con lo que falta · ⚖️ decisión del dueño.
